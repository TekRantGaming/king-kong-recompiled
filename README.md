## Getting started

**You need:** Windows 10 or 11 (64 bit) or Linux (x86 64 bit), a graphics card that supports DirectX 12 or Vulkan, about 7 GB of free space, and a disc image you made from your own Peter Jackson's King Kong Xbox 360 disc (see [Which version you need](#which-version-you-need)).

1. Download the **KingKong-...-windows-x64.zip** file from the [latest release](https://github.com/TekRantGaming/king-kong-recompiled/releases/latest) and unzip it anywhere. On Linux, see [Linux and Steam Deck](#linux-and-steam-deck-experimental).
2. Run **king_kong.exe**. The launcher opens on its first setup.
3. Choose **Select disc image** and pick your King Kong disc image. The launcher checks it, copies the game files (about 6.3 GB) into a `game` folder next to the exe and takes its artwork from them.
4. The graphics are prepared once, with one progress bar. Then setup offers **Auto detect**, the HD texture pack and the PS2 cutscenes, and walks you through the graphics options and button prompts.
5. Press **PLAY**.

The download contains only this port. **No game files are included**: they come from your own disc. Your saves and settings are kept in `Documents\king_kong`. The port is also listed on [Quiver Launcher](https://quiverlauncher.com/apps/peter-jackson-s-king-kong-the-official-game-of-the-movie-king-kong-pc-port), where you can see how it runs for other players.

### Which version you need

The port is made for this disc only. The 2005 PC version and discs for other platforms will not work.

| | |
| --- | --- |
| Game | Peter Jackson's King Kong: The Official Game of the Movie |
| Disc | Xbox 360, USA and Europe (English, French, German, Spanish, Italian, Dutch, Swedish, Norwegian, Danish, Finnish) |
| Title ID | `555307D3` |
| Game version | `0.0.0.1` (the original disc release) |
| Disc image | `.iso`, 7,834,892,288 bytes |
| SHA-1 | `075F43709E9C9A095E099AB5056CC04B768288D1` |
| MD5 | `35D671ED4E9EAD9E6B288A3441B6C8F9` |

The launcher checks the title ID before it installs. To check your disc image yourself, run this in PowerShell and compare the result with the SHA-1 above:

```powershell
Get-FileHash "C:\Games\King Kong.iso" -Algorithm SHA1
```

The [game files page](https://kong.tekrantgaming.com/game-files.html) explains how to make an image of your own disc. We can't provide, link to or help you find game files.

### Linux and Steam Deck (experimental)

**This is a native Linux program**, not the Windows version under a translation layer. It's one AppImage file with the Vulkan renderer. The name never changes, so a Steam shortcut to it keeps working from one version to the next.

1. Download **KingKong-linux-x86_64.AppImage** from the [latest release](https://github.com/TekRantGaming/king-kong-recompiled/releases/latest) and put it in a folder of its own, for example in your home folder.
2. In your file manager, open its Properties and allow it to run as a program, or run `chmod +x` on it in a terminal.
3. Start it. The launcher opens on its first setup: pick your disc image and set up as on Windows.
4. To play from Steam's Game Mode, use **Add to Steam** on the launcher's Home screen, which also adds the artwork. You can also choose **Games > Add a Non Steam Game to My Library** in Steam's desktop mode.

The game files, `king_kong.toml` and the `logs` folder sit next to the AppImage, and the launcher's About tab opens your save folder in one click. It needs FUSE 2 to mount the AppImage, and `curl` for downloads.

**What differs from Windows:** DirectX 12 is a Windows API, so Linux always uses Vulkan. DLSS and FSR 3.1 are Windows only for now, FSR 4 needs DirectX 12, and Intel has no Linux version of XeSS, so on Linux the upscalers are FSR 1 and NIS. Linux support is newer than Windows support, so please [tell us](#reporting-a-problem) if something doesn't work.

A Mac version is planned, and it may also lead to Arm builds. Until then, Windows on Arm PCs can try the Windows version through Prism.

#### The Windows version through Proton

Before the native version, Linux and Steam Deck players ran the Windows download through Steam's **Proton**. That build was tested on a ROG Ally (Z1 Extreme) with Bazzite, where it held 120 FPS on the 10 W power profile. To play that way:

1. Unzip **KingKong-...-windows-x64.zip** anywhere, for example in your home folder.
2. In Steam (in desktop mode on a Steam Deck), choose **Games > Add a Non Steam Game to My Library**, browse to **king_kong.exe** and add it.
3. Right click it in your library, choose **Properties > Compatibility**, tick **Force the use of a specific Steam Play compatibility tool** and pick **Proton Experimental**.
4. Start it from Steam (Game Mode works too). The first start takes about half a minute while Steam sets Proton up for it. Pick your disc image as on Windows: your Linux home folder is on the **Z:** drive.

Your saves and settings are kept in Steam's Proton folder for the game, under `steamapps/compatdata`.

## Online co-op (early access)

Two players, one story. The host picks a chapter or one of their saves, a friend joins, and both games load it together.

<img src="docs/images/v2/coop.jpg" alt="The launcher's Play Online Co-op page" width="49%">
<img src="docs/images/v2/lobby.jpg" alt="The co-op lobby" width="49%">

1. Open **Play Online Co-op**, directly under **Play** on the Home screen.
2. **Host a game** and choose any chapter or one of your saves.
3. Invite a Steam friend to the lobby, or share your 6 character code.
4. Both players press **Ready**, and both games load the chapter together.

**Joining:** accept an invite, pick a friend who is playing now from the list, or type a code. Invites and the friends list need Steam to be open, and joining with a code works without it. Windows and Linux players can play together.

**Playing together:** the host's game runs the story and the enemies, and your shots count in it. You see your partner in the world with their name over their head. Fall, and you come back next to your partner. The guest's own saves are kept apart from the host's. There's no voice chat in the game, so use Steam or Discord.

**You need:** the same version of the port on both PCs, and each player needs their own copy of the game.

> [!WARNING]
> **Online co-op is in early access.** It works, and it's still rough in places. Not every chapter has a player model for the guest yet, the guest's game sometimes reloads to catch up with the host, people and mission state can drift out of step between the two games, and now and then a player is moved out of the map. Some chapters may not let you go on. For the smoothest game, play single player. If something goes wrong, the launcher's co-op pages have an **Open logs folder** button: please send the logs to us on the [Discord](https://discord.gg/8eakYSvBZS).

## The launcher

Everything is set up before the game starts, with a controller, the keyboard or the mouse. **The launcher is the game's main menu**: the Venture rolls on the stormy sea behind it, live, with the menu's own music and the sound of the sea. On low end PCs such as the Steam Deck, and during setup, it shows stills from the movie trailer instead. It looks and sounds like the game, using your own copy of it: the King Kong logo, the main menu music and the game's own menu sounds. Nothing from the game comes in the download. It follows the game's **Language** setting (English, French, German, Spanish or Italian). Settings are saved to a plain text file, `king_kong.toml`, next to the game, and every settings page has **Reset page** to put just that page back to its defaults.

**Settings** has eight tabs: Display, Graphics, Audio, Controls, Gameplay, Cheats, Advanced and About. The panel beside them explains each setting: what it does, what it costs and its default.

## Graphics

The game is drawn by a renderer made for it, with DirectX 12 (the default on Windows) or Vulkan, at any resolution up to 7680 x 4320. If the one you chose doesn't start, the game uses the other and tells you. Vulkan is the default on Intel integrated graphics and the only choice on Linux and the Steam Deck. The Xbox 360 emulation renderer has been removed, and older renderer settings migrate automatically. If neither API can start, update your graphics driver and check the requirements above. For help, use the Discord link above and include the logs folder.

The game shots below are from the V-Rex chapter; in each pair only the setting being compared changes.

### Ambient occlusion

Soft shading where surfaces meet: in corners and creases, and on the ground under rocks, grass and people, so they sit in the scene instead of floating on it. It stays under the game's own distance fog, so far off walls don't show through the haze. Water, smoke, fire, fur and the sky are drawn after it, so they are never darkened. Turn it on with **Ambient occlusion**, at **Light**, **Medium** or **Strong**, and **AO quality** sets how smooth it is. The High and Ultra presets turn it on. It costs about 1 ms a frame at 1440p on a fast card.

### Global illumination

Light bounces, so sunlit rock tints the shadow beside it and the green of the jungle falls on the people in it. Only what is on screen bounces light. **Global illumination** comes at Low (light reaches about 3 m), Medium (about 5 m and about 1 ms a frame at 1440p on a fast card) or High (about 8 m with a finer blur), and **GI distance** sets how far into the scene it works.

### Shadows, water and light

- **Shadows**: High draws the game's own shadows at twice the detail with soft edges, and Ultra softens them the farther they fall. No shadows are added. Original is the game's own.
- **Water reflections**: rocks, trees and the ship on screen mirror in the sea, rivers and swamps. Original is the game's own reflection.
- **Light shafts**: soft shafts of sunlight through the fog, Volumetric low or high, where the game has fog and a sun shadow. Original is the game's own light beams only.
- **HDR (experimental)**: off by default, and found in the <kbd>F8</kbd> graphics panel. Peak brightness comes from the Windows HDR Calibration app.

### Ultrawide

On a 21:9 or 32:9 screen the game fills the whole width and shows more on the left and right, with nothing stretched. The HUD, subtitles and menus stay in the middle. There is nothing to switch on. Window size, Resolution and the first setup also list these sizes, with black bars above and below, so you can try ultrawide on a 16:9 screen. Nothing changes on a 16:9 screen otherwise.

### DLSS, FSR 3.1, FSR 4 and XeSS

The game can draw fewer pixels and rebuild a sharp picture from several frames. Only the upscalers your graphics card can run are listed, and the best one is chosen for you, at Quality. There's no frame generation: every frame you see is drawn by the game.

| Upscaler | Runs on | Windows | Linux |
| --- | --- | :---: | :---: |
| NVIDIA DLSS | GeForce RTX cards | ✅ | |
| AMD FSR 4 | Radeon RX 9000 cards, with DirectX 12 | ✅ | |
| AMD FSR 3.1 | Almost any card | ✅ | |
| Intel XeSS | Best on Intel Arc, runs on other cards too | ✅ | |
| AMD FSR 1 and NVIDIA NIS | Any card, light scaling and sharpening | ✅ | ✅ |

**Upscaler mode** picks how many pixels the game draws: Native AA (DLAA with DLSS), Quality, Balanced, Performance and Ultra Performance.

### AMD FSR 1 and NVIDIA Image Scaling

Pick **AMD FSR 1** or **NVIDIA NIS** under **Upscaler**. Both work on any graphics card. They scale the game's picture up to your screen and sharpen it, so drawing fewer pixels for a higher frame rate still looks crisp. **Upscaler mode** picks how many pixels the game draws: **Native**, **Quality**, **Balanced** or **Performance**, with the resolution shown for your screen.

### Original Xbox 360 or Remastered, and presets

**Look** at the top of the **Graphics** page switches between **Original Xbox 360**, the game as it was on the console (720p at 30 FPS, its own antialiasing and texture filtering, the 69° field of view, motion blur and fog, no ambient occlusion and no upscaler), and **Remastered**, with every setting, at 60 FPS. In Remastered, a **Preset** sets several things at once:

| Preset | Upscaler | Upscaler mode | Render quality | Antialiasing | Texture filtering |
| --- | :---: | :---: | :---: | :---: | :---: |
| Low | the best for your card | Performance | Performance | FXAA | 2x |
| Medium | the best for your card | Quality | Quality | FXAA | 4x |
| High | the best for your card | Quality | Native | FXAA | 16x |
| Ultra | the best for your card | Quality | Native | FXAA | 16x |
| Steam Deck | the best for your card | Quality | Native | FXAA | 2x |

| Preset | Ambient occlusion | Global illumination | Shadows | Water reflections | Light shafts |
| --- | :---: | :---: | :---: | :---: | :---: |
| Low | off | Low | Original | Original | Original |
| Medium | off | Medium | Original | Original | Original |
| High | Strong | High | High | Screen space | Volumetric low |
| Ultra | Strong, High quality | High | Ultra | Screen space | Volumetric high |
| Steam Deck | off | Low | Original | Original | Original |

**Render quality** is used by FSR 1, NIS and no upscaler, and **Upscaler mode** by DLSS, FSR 3.1, FSR 4 and XeSS. A preset leaves the frame rate, motion blur, screen blur and distance fog as they are. Change any setting yourself and the preset shows **Custom**. Auto detect picks a preset for your PC at setup, and **Use recommended for my PC** picks one at any time.

## Performance

- **Any frame rate**: 30 like the console, 60, 120, 144, 240 or unlimited. Animations, physics, particles, water, the camera and timing run at the right speed, from the rowing crew to Kong's grabs.
- **Ready before you play**: the graphics are prepared once on the first start. The port ships with a list of 17,652 graphics pipelines, built with the help of players who chose to share theirs, so new places stutter far less.
- **Benchmark** on the main menu: a recorded route through four chapters with your graphics settings. A standard run takes about 10 minutes, and the results stay on your PC.
- **Performance metrics** with <kbd>F2</kbd>: FPS only, or Full, with a frame time graph, the graphics card's load, temperature, clock and memory, the processor and memory use, the graphics API and the upscaler.

## In the game

**Pause menu:** press Start or Esc for Resume, Photo mode, Controls, Gameplay, Settings, Load last checkpoint, Save game where the game offers it, Quit to main menu and Quit game. Settings that can change while you play do so at once.

**Photo mode:** fly a free camera around the paused scene, with looks and tints, depth of field, vignette, film grain, letterbox bars, cel shading and more. Pictures save at full resolution with no menus.

**Saving:** the game saves when you choose Save game, and when you quit from the pause menu with Quit to main menu or Quit game. Checkpoints are not saves, so if you close the window another way, for example with Alt+F4, progress since your last save is lost.

## Workshop and Extras

**The Workshop** on the main menu has texture packs and mods, downloaded and switched on from the launcher:

- **HD texture pack** (2.6 GB, offered at setup): textures at four times their original size, keeping the game's own look.
- **Kong UHD Textures**: real photographed materials mixed with AI upscaling, so the look changes from the original.
- **Comic Book Texture Pack**, best with the built in **Cel shading** mod.
- **Your own**: import a texture pack or a mod as a ZIP. [MODDING.md](MODDING.md) and the [Mods page](https://kong.tekrantgaming.com/mods.html) explain how to make them.

The texture packs are separate downloads, and none is needed to play.

**Extras:**

- **PS2 cutscenes** (1.9 GB, offered at setup): the PlayStation 2 version's cutscenes between the missions, upscaled. The next chapter loads after it.
- **The Weta Artbook**: six concept paintings from the PS2 bonus disc, with zoom and Save to PC. The launcher downloads the bonus disc from archive.org and keeps only the paintings.
- **The user manual**, and **every Extras item** open from the start.
- **Original main menu**: the game's own Xbox 360 main menu, as it was.

### Known issues

- Above 30 fps a few character animations are not quite right yet. 30 fps, the Original look's rate, plays them correctly.
- There can be a short pause when the game loads the next area. The game does the same on the Xbox 360.
- The prerendered videos pause for a moment every couple of seconds while the video player keeps to the video's timing. This is being looked into.
- Under Proton the launcher has no stills from the movie trailer (Proton can't play the trailer to it). It shows the title screen from your first play instead.
- With FSR, a few short stutters remain in very busy scenes such as parts of Ann's chapter, when the camera swings quickly.
- The first time you see a new effect it has to be prepared. Many are prepared before you play and the game waits only a moment for the rest, so there are no long pauses, but an object can occasionally appear a moment late the first time. Effects are saved, so this only happens once.
- Online co-op has its own [list above](#online-co-op-early-access).
- Three bugs from the original Xbox 360 game are still there: the V-Rex tail can get stuck at the wall in the Call Kong level, the swamp chapter can freeze while loading, and the Kong pillar lifting prompt can vanish or leave Kong stuck lifting.

### The shader pack

The game needs its effects (shaders) prepared before they can appear, which used to cause short pauses. Now the launcher prepares them on the first start and after an update, with one progress bar, and the game doesn't start until they are ready. This takes a few minutes the first time. The **Shaders** status on the Home screen shows how they stand: select it to prepare them again, or use **Rebuild shaders** at the bottom of **Settings > Graphics**.

The port also comes with a list of 17,652 graphics pipelines, collected by playing through the game and from players who share theirs with **Online players** on. They are prepared with the shaders, so new places stutter far less. The launcher still fetches the older pack from the [shader-packs release](https://github.com/TekRantGaming/king-kong-recompiled/releases/tag/shader-packs) by itself when a newer one is out. You don't need to do anything.

### Updates

When the launcher opens it asks GitHub whether a newer version of the port is out. **Update now** checks the download, installs every file of the new version, removes old files the game no longer uses (never your saves, settings or mods) and restarts the launcher, and everything is put back as it was if something goes wrong. Your installed game, saves and settings stay as they are. Turn the check off on the **About** tab. **Change version** on the About tab switches between the stable version and the beta. The shader pack updates itself on its own.

### Online player count

On by default: the setup screen explains it, players who already have the game are told once, and you can switch it off at any time on the **About** tab. While it's on, the top right of the launcher shows how many players are online, and the launcher checks in with the port's server every 5 minutes, also while you play. A check in holds:

- a random number that isn't linked to you, deleted when you switch it off
- the port's version (and the newest one it was offered), and whether it's stable or beta
- Windows or Linux (Linux and Steam Deck players count as Linux, Proton included)
- whether you're in the game

That's all. No name, account, IP address or anything from your PC is kept, and installs that haven't checked in for 90 days are deleted. Nothing is sent while it's off. The server is the port's own, on Cloudflare.

The same switch shares a little more to help the game run well on every PC: anonymous graphics data and a short performance summary when you quit (frame rate, graphics card, driver and main settings), and a crash report, if there was one, on the next start.

### Reporting a problem

Everything useful is in the `logs` folder next to `king_kong.exe` (next to the AppImage on Linux):

- `king_kong.log` describes your settings, and every 10 seconds it notes the frame rate, the 1% low and any frames that took over 50 or 100 ms. That shows exactly where stutter happens.
- If the game crashes, a report is saved on your PC, with your user name and personal folders removed: `crash-<date>.txt` and `crash-<date>.dmp`. **Settings > Advanced > Saved crash reports** opens the folder.

Please attach them to an [issue](https://github.com/TekRantGaming/king-kong-recompiled/issues) together with your CPU, graphics card and the resolution you play at, or ask on the [Discord](https://discord.gg/8eakYSvBZS).

## About the port

*Peter Jackson's King Kong: The Official Game of the Movie* came out in 2005 on PC and on every console of the time. The Xbox 360 version was a launch title for the console, with upgraded graphics and its own achievements.

Until now the only way to play it was on an Xbox 360. On the Xenia emulator it boots, but it gets stuck right at the start of the first level and can't be played. This port runs it natively on Windows and Linux, fixes that freeze, and adds the options you would expect from a PC release.

No emulator runs while you play. The Xbox 360 runs PowerPC code, and a recompiler translates every function of the game's program, read from your own disc image, into code a PC processor runs directly. Our renderer then takes the game's requests to draw and draws them with DirectX 12 or Vulkan, with the console's shaders translated for your graphics card.

Version 1.0.0 came out on 5 October 2026. 25 days and 17 public beta versions later came 2.0.0, and the community's reports shaped every one.

### The "VENTURE" freeze

On Xenia this game gets stuck at the start, looking at the ship's name "VENTURE" ([xenia-project/game-compatibility#1302](https://github.com/xenia-project/game-compatibility/issues/1302)). The cause is how disc reads finish. The game streams music and voice lines with reads it expects to finish right away. The emulator finishes them but reports them as still in progress, so the game thinks it got no data. No voice line ever plays, and the opening waits forever for one to end.

This port finishes those reads the way the console does (`kk/src/io_fix.cpp`), so music, voice lines and the opening all work.

<details>
<summary><b>Building from source (for developers)</b></summary>

You need Visual Studio 2022 Build Tools with Clang, CMake and Ninja.

```powershell
.\setup.ps1 -Iso "C:\Games\King Kong.iso"   # downloads the SDK, unpacks your disc, translates the code
kk\build.bat kk-release                      # compiles
```

The finished game is in `kk\out\build\kk-release`. `Build King Kong.bat` does all of this in one go and puts the result in a `KingKong` folder. Point the game at your files with `--game_data_root`, or keep them in a `game` folder next to the exe. The Linux build is described in [native-renderer/docs/linux.md](native-renderer/docs/linux.md).

For testing, `kk\build.bat kk-dev` builds a version with developer aids that release builds leave out. Set `KK_DEV_AUTOSKIP=1` and it presses through the intros, menus and story videos into gameplay on its own, logging `KK dev: gameplay reached`. Add `KK_DEV_WANDER=1` to keep walking and looking around after that. The shader pack is built by running every chapter this way with its own `--cache_root`, then `python tools/make_shader_pack.py <version> <out> <cache folders...>`.
